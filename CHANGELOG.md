## 0.1.0 (2026-10-25)

First tracked version: everything merged to `main` up to and including PR #11.

### Features

- **foundation:** pnpm + Turborepo monorepo, pure TypeScript queue engine, Supabase schema with
  RLS, Next.js PWA shell in Hebrew (RTL) and English, docs and agent setup.
- **guest:** join a table by QR or code without signing in; anonymous sign-in as the guest
  identity; catalog search with YouTube karaoke versions; song requests checked by the rules
  engine; refreshed guest theme, copy and wait estimate.
- **dj:** DJ console with queue manager, YouTube player and mixer; drag and drop to reorder the
  queue; manually moved songs are tagged "moved by hand".
- **admin:** venue admin for tables, printable QR sheet and settings; manage the queue from the
  admin; tables tonight board; DJ console inside the admin with table cards and wait estimates.
- **web:** staff shortcuts on the signed-in home page; guest join link on the login page.

### Bug Fixes

- **db:** storage bucket setup applies on bare Postgres; dashboard-style Supabase URLs accepted.
- **guest:** join works on WebKit and before hydration; guest flow hardened after the staged event.
- **dj:** the player re-attaches when the night is reopened; the table card stays open through the
  scroll that preceded the tap.
